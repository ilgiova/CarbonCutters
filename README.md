# CarbonCutters 🌍♻️

[![Play the Game](https://img.shields.io/badge/Play-CarbonCutters-success.svg?style=for-the-badge)](https://ilgiova.github.io/CarbonCutters/)
[![Game Engine](https://img.shields.io/badge/Godot-Engine-blue.svg?style=for-the-badge)](https://godotengine.org/)

**CarbonCutters** is an educational video game developed as part of an international collaboration project between **SUPSI** (University of Applied Sciences and Arts of Southern Switzerland) and **PSU** (Penn State University). 

The game's objective is to raise awareness about environmental impact and the importance of adopting sustainable practices through interactive gameplay mechanics.

## 🎮 Play the Game
You can play CarbonCutters directly from your web browser without installing anything. 
**[Play now on GitHub Pages](https://ilgiova.github.io/CarbonCutters/)**

## 🌟 Core Features & Thematic Pillars
The game design is built to integrate complex concepts into accessible mechanics, focusing on three main themes:

*   **Recycling:** Players are challenged to implement waste sorting and management systems, optimizing resources to reduce environmental impact.
*   **Renewable Energy:** Progression in the game requires transitioning to clean energy sources. The player must balance and manage infrastructures based on renewable energies to power the game ecosystem.
*   **Cross-Cultural Exchange:** Designed between Switzerland and the United States, the game integrates diverse cultural perspectives, highlighting how the climate crisis is a global challenge that requires international cooperation and shared solutions.

## 🛠️ Tech Stack
*   **Game Engine:** [Godot Engine](https://godotengine.org/) (Version 4.6)
*   **Scripting:** GDScript
*   **Deployment:** GitHub Pages (WebAssembly/HTML5 export)

## 🚀 Local Setup (For Developers)
To run the project locally, explore the source code, or contribute to the development, follow these steps:

1. Clone the repository to your local machine:
   ```bash
   git clone [https://github.com/ilgiova/CarbonCutters.git](https://github.com/ilgiova/CarbonCutters.git)
   ```
2. Download and install **Godot Engine**.
3. Launch Godot, open the Project Manager, and click on **Import**.
4. Navigate to the cloned repository folder and select the `project.godot` file.
5. Once the editor is open, click the Play button (or press `F5`) to start the main scene and test the game loop.
